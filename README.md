# 🚀 Featured Projects

## 🤖 PromptStack – AI Chat & Image Generation SaaS

AI SaaS platform for Gemini 2.5 Flash chat and text-to-image generation.

### Highlights

- Token-by-token LLM streaming over **Socket.io** WebSockets with live Markdown and code rendering
- **Semantic chat memory** — message embeddings + cosine similarity retrieve the top 3 relevant past messages, sent with the last 5 to keep context relevant and prompt size bounded
- **Redis cache** for sessions, active chats and repeated prompts (TTLs from 15 min to 30 days) with invalidation and an in-memory fallback
- **Stripe** credit billing via signature-verified webhooks
- JWT auth and 11 REST APIs following MVC; generated images stored on the ImageKit CDN

**Tech Stack**

`React.js` • `Node.js` • `Express.js` • `MongoDB` • `Socket.io` • `Redis` • `Stripe` • `Gemini API` • `ImageKit` • `JWT`

🌐 **Live Demo:** https://promptstack-ai.vercel.app/ &nbsp;|&nbsp; 💻 **Code:** [GitHub](https://github.com/ideveshtripathii/PromptStack)

## 💼 InsiderJobs – AI-Powered Job Portal

MERN job portal with separate candidate and recruiter flows.

### Highlights

- Candidate (Clerk) and recruiter (JWT + bcrypt) flows covering job posting, search, applications and a Pending/Accepted/Rejected pipeline across **19 REST APIs**
- **AI resume parser** — extracts PDF text and uses Gemini 2.5 Flash to return structured JSON (skills, experience, education), with a fallback parser
- **AI mock interview simulator** — role-specific questions, spoken answers via the Web Speech API, and AI-graded scores and feedback with saved history
- Cache-aside **Redis** caching for job listings, cutting read time from ~200 ms to under 10 ms on cache hits
- Svix-verified Clerk webhooks and Sentry monitoring

**Tech Stack**

`React.js` • `Node.js` • `Express.js` • `MongoDB` • `Redis (Upstash)` • `Gemini API` • `Clerk` • `Cloudinary` • `Sentry`

🌐 **Live Demo:** https://insiderjobsfullstack.vercel.app/ &nbsp;|&nbsp; 💻 **Code:** [GitHub](https://github.com/ideveshtripathii/Insiderjobs)
